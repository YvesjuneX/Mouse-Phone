# Aplicación móvil

La app usa React Native y Expo SDK 58. En **Ordenadores** puedes buscar equipos en la Wi-Fi, añadir uno por IP y guardarlo. Al conectarte se abre el **Panel táctil**, con movimiento, clic tocando, rueda vertical y controles multimedia.

```powershell
npm.cmd install
npm.cmd start -- --lan
```

Instala Expo Go en el móvil, conecta el móvil y el ordenador a la misma Wi-Fi y escanea el código QR mostrado por Expo. En Android, acepta el permiso de dispositivos de red local cuando la app lo solicite.
